# Exploring-Global-Youtube-Trends
## Project Overview

This project analyzes global trends among the top YouTube creators using interactive dashboards built in Tableau. The goal is to uncover patterns in content categories, audience reach, geographic distribution, and monetization potential across nearly 1,000 of the most successful YouTube channels worldwide.

By combining channel performance metrics (subscribers, views, uploads, and earnings estimates) with country-level demographic indicators, the project explores how geographic and socioeconomic factors may influence creator success.

* The analysis focuses on identifying:
* The most dominant content categories on YouTube
* Geographic distribution of top creators
* Relationships between country-level factors and channel performance
* Patterns in engagement, monetization, and channel growth

## Business Understanding

As digital media platforms become central to entertainment, marketing, and entrepreneurship, understanding what drives creator success on YouTube is increasingly valuable.

This project approaches the dataset from a data-driven business analytics perspective to answer questions such as:

* Which content categories dominate the platform?
* Do country-level demographics influence creator success?
* Are subscriber counts strongly correlated with engagement or earnings?
* How do top creators differ across global regions?

Insights from this analysis can help:

* Aspiring creators choose strategic content niches
* Marketers identify high-performing creator segments
* Analysts understand global digital media consumption trends

## Dataset

The dataset comes from a YouTube Statistics dataset published on Kaggle and includes information on 995 top-performing YouTube channels worldwide.

Key Variables

* Channel name
* Subscribers
* Video views
* Number of uploads
* Channel creation date
* Category/type of content
* Estimated monthly earnings
* Estimated yearly earnings

## Project Highlights

* Analyzed 995 global YouTube channels
* Built three interactive Tableau dashboards
* Integrated channel-level performance metrics with country-level demographics
* Conducted geospatial analysis, ranking analysis, and category comparisons

## Reflections

This project highlighted the importance of combining data visualization with contextual storytelling. While raw metrics such as subscribers and views provide valuable signals, understanding geographic distribution, category trends, and monetization differences allows for deeper insights into digital creator success.
